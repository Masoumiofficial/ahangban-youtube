[▶ ریلز مستقل — ۱:۲۶٫۱، 1080×1920، 30fps](downloads/ahangban-music-film-reel.mp4)

کاربر [نمونهٔ خشک 008](content/008-voice-lab/README.fa.md) را پسندید و ادامهٔ تدوین را خواست. همان زن **voice-06** و مرد **voice-07** حفظ شده‌اند؛ دو اجرای تأییدشده عیناً بازاستفاده شده‌اند. ضبط واقعی سجاد، کلون و تغییر سرعت/زیر و بم نیست. تأیید نمونه به معنی شنیدن همهٔ جمله‌های تازه یا تأیید نهایی تدوین نیست.

پنج موسیقی، هر کدام **۳۰ ثانیه در یوتیوب و ۱۲ ثانیه در ریلز**؛ جمعاً ۱۵۰ و ۶۰ ثانیه موسیقی. شروع پرسشی و نخستین موسیقی حدود ثانیهٔ ۱۲. پنج فضای سینمایی، ۲۰ شات موسیقی یوتیوب و ۱۵ شات ریلز با برش‌های نزدیک به onset انرژی، گذار نوری، طیف واقعی صوت و زیرنویس فارسی. لوگوی رسمی و کاورها دست‌نخورده‌اند. ریلز برای حفظ موسیقی، عمداً بیشتر از یک دقیقه است.

هر دو فایل decode کامل و بررسی فنی را گذرانده‌اند؛ **۱۳ آزمون نسخهٔ جدید پاس شده‌اند**. بازبینی شنیداری نهایی و حقوق آثار پیش از انتشار لازم است. **هیچ انتشار یوتیوب/اینستاگرام یا خرید اشتراک انجام نشده است.**

## نسخهٔ تاریخی 007 — تحویل فنی، اما کیفیت گفتار مورد قبول کاربر نیست

[▶ ویدیوی کامل یوتیوب](downloads/ahangban-cosmic-youtube.mp4) — **۳:۲۳، 1920×1080، 25fps**

[▶ ریلز مستقل اینستاگرام](downloads/ahangban-cosmic-reel.mp4) — **۵۸٫۷ ثانیه، 1080×1920، 30fps**

[تامبنیل یوتیوب](downloads/ahangban-cosmic-youtube-thumbnail.jpg) · [کاور ریلز](downloads/ahangban-cosmic-reel-cover.jpg) · [جزئیات، کپشن، زیرنویس، منابع و بررسی فنی](content/007-cosmic-ai/README.fa.md)

صدای زن فارسیِ تازه و منتخب `voice-05` و راوی عمومی مصنوعی `voice-04`؛ **هیچ ضبط واقعی سجاد یا کلون شخصی در این نسخه نیست.** کاربر مسیر ضبط/کلون را کنار گذاشته است. محیط‌های سوررئال تولیدشده با هوش مصنوعی، حرکت نرم دوبعدی و نور متصل به صوت، کاورهای اصلی، زیرنویس درشت با فونت لاله‌زار و لوگوی رسمیِ دست‌نخورده.

برای هر آهنگ **۲۰ ثانیه در یوتیوب و ۸ ثانیه در ریلز** در نظر گرفته شده؛ گفتار روی موسیقی نیست. نام رسانه و سایت گفته و نمایش داده می‌شوند. این پنج انتخاب، رتبه‌بندی آماری یا ادعای ترند امروز نیستند.

بررسی فنی با بازبینی شنیداری/سلیقه‌ای یا مجوز موسیقی یکسان نیست. حقوق آثار و تلفظ/برش نهایی پیش از انتشار بررسی شوند. **هیچ انتشار یوتیوب/اینستاگرام یا خرید اشتراک انجام نشده است.**

نسخهٔ [006 بدون مجری با صوت قبلی](content/006-faceless-music/README.fa.md)، [004 با ضبط واقعی](downloads/ahangban-first-video-final.mp4) و پایلوت ردشدهٔ چهره صرفاً سابقه‌اند؛ فایل‌هایشان حفظ شده است. پژوهش کلون دیگر کار معوق نیست و نباید خودکار از سر گرفته شود.

## نصب انجام‌شده

هر ۱۱ اسکیل [YouTube Agent](https://github.com/Jakeschincariol/youtube-agent-skill)
به روش محلیِ مستندشده در مخزن اصلی، بدون تغییر در `.claude/skills/` قرار گرفته‌اند.
ابزارهای همراه فقط به Python 3 نیاز دارند و وابستگی خارجی ندارند.
نسخهٔ دقیق منبع و مجوز MIT در همان پوشه ثبت شده است.

| اسکیل | کاربرد |
| --- | --- |
| `/yt-script` | سناریو و هوک |
| `/yt-package` | عنوان و تامبنیل |
| `/yt-edit` | پیشنهاد برش از روی زیرنویس |
| `/yt-comment` | دسته‌بندی کامنت‌ها و پیش‌نویس پاسخ |
| `/yt-plan` | برنامهٔ هفتگی |
| `/yt-viral` | بررسی ایده‌ها و ویدیوهای پربازده |
| `/yt-retention` | تحلیل فایل نگهداشت مخاطب |
| `/yt-shorts` | استخراج ایدهٔ شورت از ویدیوی بلند |
| `/yt-seo` | توضیحات، تگ و جست‌وجو |
| `/yt-chapters` | فصل‌بندی از روی زیرنویس |
| `/yt-audit` | بررسی کانال |

در Arena، درخواست خود را به زبان طبیعی بنویسید؛ راهنمای `AGENTS.md` محل اسکیل‌ها
را مشخص می‌کند. نصب فایل‌ها به معنی اضافه‌شدن فرمان‌های اسلش به رابط Arena نیست.
در Claude Code، اسکیل‌ها از پوشهٔ محلی پروژه شناسایی می‌شوند.

### تست مستقیم ابزار هوک

```bash
python3 .claude/skills/yt-script/hookscore.py --hook "Why do your first 30 seconds lose viewers?"
```

ابزارهای امتیازدهی و تشخیص واژه عمدتاً انگلیسی‌محورند؛ نتایج آن‌ها برای متن فارسی
نباید معیار معتبر زبانی یا تضمین بازدید تلقی شوند.

### تنظیم لحن کانال

قالب `.claude/youtube/templates/voice.md` را با نمونه‌های واقعی تکمیل کنید و در
`.claude/youtube/voice.md` ذخیره کنید. راهنمای این پروژه این مسیر را می‌خواند؛
مسیر پیش‌فرض خود اسکیل‌های بالادستی `~/.claude/youtube/voice.md` است.
برای استخراج لحن، سه ویدیو یا متن واقعی از کانال لازم است.

### نصب جایگزین به صورت افزونه در Claude Code

Claude Code در محیط فعلی نصب نیست؛ ثبت marketplace در این محیط اجرا نشده است.
اگر روی دستگاه خود Claude Code دارید، روش افزونهٔ مخزن اصلی چنین است
(این روش جایگزین نصب محلی است؛ نیازی به نصب دوبارهٔ هر دو نیست):

```text
/plugin marketplace add Jakeschincariol/youtube-agent-skill
/plugin install youtube-agent
```

این بسته به حساب یوتیوب وارد نمی‌شود و هیچ ویدیو یا کامنتی منتشر نمی‌کند.
برای تحلیل واقعی، متن ویدیو، داده‌های عمومی قابل دسترسی یا خروجی YouTube Studio لازم است.

## داشبورد اختصاصی اتصال به یوتیوب

یک برنامهٔ وب فارسی با OAuth گوگل و دسترسی **فقط‌خواندنی** اضافه شده است.

```bash
npm ci
cp .env.example .env
# تنظیمات Google Cloud و متغیرهای محیطی را طبق راهنما تکمیل کنید.
npm start
```

رابط بدون تنظیمات هم باز می‌شود، اما اتصال واقعی فقط با تنظیم OAuth و دسترسی سرور
به گوگل فعال است. **محیط فعلی Arena به سرورهای گوگل دسترسی خروجی ندارد**؛ برای اتصال
واقعی این برنامه را روی دستگاه یا میزبانی مناسب اجرا کنید.

[راهنمای فارسی Google Cloud، اجرا، امنیت و قطع اتصال](docs/youtube-connection.fa.md)

این برنامه کانکتور داخلی Arena نیست. می‌توانید گزارش JSON داشبورد را دانلود کنید و
در صورت تمایل برای تحلیل در گفتگو بفرستید. توکن‌ها در گزارش قرار نمی‌گیرند.

تست‌های برنامه: `npm test` (با شبیه‌سازی گوگل، نه حساب واقعی).

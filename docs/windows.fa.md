# اجرای آهنگ‌بان روی ویندوز

## مرحلهٔ اول: فقط بازکردن داشبورد

۱. نسخهٔ LTS از Node.js را از https://nodejs.org نصب کنید (نسخهٔ ۲۲ یا بالاتر).
در نصب معمولی، گزینهٔ افزودن به PATH فعال است. سپس ترمینال را ببندید و دوباره باز کنید.

۲. بستهٔ پروژه را با Extract All از حالت ZIP خارج کنید. برنامه را داخل ZIP اجرا نکنید.
به پوشه‌ای بروید که فایل `package.json` در آن قرار دارد. از نوار آدرس File Explorer،
`powershell` را بنویسید و Enter بزنید تا PowerShell در همین پوشه باز شود.

۳. نسخه‌ها را بررسی کنید:

```powershell
node --version
npm.cmd --version
```

اگر فرمان‌ها شناخته نشدند، ابتدا نصب Node.js و بازکردن دوبارهٔ PowerShell را بررسی کنید.
پسوند `.cmd` باعث می‌شود به تغییر Execution Policy پاورشل نیاز نداشته باشید.

۴. پیش از اولین اجرا (اگر قبلاً `.env` ساخته‌اید، آن را بازنویسی نکنید):

```powershell
npm.cmd ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
npm.cmd start
```

با مرورگر **همین کامپیوتر** به http://localhost:3000 بروید. پنجرهٔ PowerShell را باز بگذارید.
در این مرحله دیدن «منتظر تنظیمات سرور» طبیعی است؛ حساب گوگل هنوز متصل نشده است.
نصب وابستگی‌ها به اینترنت نیاز دارد. برای توقف سرور در PowerShell از `Ctrl+C` استفاده کنید.

فایل نمونه، HOST را برابر `127.0.0.1` قرار می‌دهد: برنامه از شبکه یا اینترنت عمومی
قابل دسترسی نیست. نیازی به Port Forwarding، زیردامنه یا بازکردن فایروال برای این اجرا ندارید.

## مرحلهٔ دوم: آماده‌کردن ورود گوگل

طبق [راهنمای کامل اتصال](youtube-connection.fa.md)، در Google Cloud پروژه بسازید،
YouTube Data API v3 و YouTube Analytics API را فعال کنید، ایمیل خود را به Test users
اضافه کنید و OAuth Client از نوع Web application بسازید.

آدرس بازگشت دقیق برای اجرای شخصی:

```text
http://localhost:3000/auth/google/callback
```

متغیر APP_BASE_URL نیز باید `http://localhost:3000` بماند. در مرورگر از همین آدرس
استفاده کنید؛ جابه‌جایی بین localhost و 127.0.0.1 می‌تواند نشست ورود را از بین ببرد.

سرور را با Ctrl+C متوقف کنید. یک SESSION_SECRET بسازید:

```powershell
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
notepad .env
```

خروجی تصادفی را مقابل SESSION_SECRET بگذارید. Client ID و Client Secret را از Google
Cloud مقابل GOOGLE_CLIENT_ID و GOOGLE_CLIENT_SECRET قرار دهید و فایل را ذخیره کنید.
سپس `npm.cmd start` را دوباره اجرا کرده و در داشبورد اتصال را شروع کنید.

**Client Secret، SESSION_SECRET، کد ورود و توکن را در چت نفرستید.** اگر به کمک نیاز
داشتید، فقط متن خطا را بدون اطلاعات محرمانه ارسال کنید. فایل `.env` را به کسی ندهید.
رمز گوگل را فقط در صفحهٔ رسمی گوگل وارد کنید.

برای اتصال زنده، هم مرورگر و هم Node.js باید به سرویس‌های گوگل دسترسی داشته باشند.
برنامه هیچ ابزار دورزدن محدودیت شبکه یا تنظیم خودکار پروکسی ارائه نمی‌کند.

## اجراهای بعدی

در همان پوشه PowerShell را باز کنید و فقط اجرا کنید:

```powershell
npm.cmd start
```

با ری‌استارت، نشست‌های حافظه‌ای پاک می‌شوند؛ دوباره ورود لازم است. این برنامه پس‌زمینهٔ
دائمی یا سرویس ویندوز نصب نمی‌کند و فقط وقتی اجراست در دسترس است.

## خطاهای رایج

- **پورت اشغال است / EADDRINUSE:** نسخهٔ قبلی سرور را ببندید. اگر پورت را تغییر دادید،
  PORT، APP_BASE_URL و redirect URI در گوگل را هم با هم تغییر دهید.
- **صفحه باز نمی‌شود:** خروجی PowerShell و روشن‌بودن سرور را بررسی کنید. نشانی HTTP است، نه HTTPS.
- **ردشدن اجرای npm.ps1:** از `npm.cmd` استفاده کنید؛ نیازی به کاهش امنیت Execution Policy نیست.
- **redirect_uri_mismatch:** آدرس بازگشت گوگل باید دقیقاً همان آدرس بالایی باشد.
- **access_denied / برنامه در حال تست است:** ایمیل ورود را در Test users پروژه اضافه کنید.
- **پیکربندی کامل نیست:** وجود فایل `.env` در کنار `package.json` و پرشدن هر سه مقدار
  GOOGLE_CLIENT_ID، GOOGLE_CLIENT_SECRET و SESSION_SECRET (حداقل ۳۲ کاراکتر) را بررسی کنید.
  فایل نباید `.env.txt` نام داشته باشد. پس از تغییر آن سرور را دوباره اجرا کنید.

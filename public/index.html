راه‌اندازی اتصال اختصاصی

از گوگل تا آهنگ‌بان، در ۴ مرحله

این یک اتصال اختصاصی برای خودت است، نه ورود مستقیم به حساب از طریق Arena.

  1. پروژهٔ Google Cloud را آماده کن

    در کنسول گوگل یک پروژه بساز و هر دو سرویس YouTube Data API v3 و YouTube Analytics API را فعال کن.

    باز کردن Google Cloud ↗

  2. صفحهٔ رضایت و کاربر آزمایشی را تنظیم کن

    در Google Auth Platform، برنامه را در حالت Testing قرار بده و ایمیل حساب گوگلی را که کانال را مدیریت می‌کند به Test users اضافه کن. دو مجوز فقط‌خواندنیِ مستندشده را اضافه کن.

  3. یک OAuth Client از نوع Web application بساز

    آدرس زیر را دقیقاً در Authorized redirect URIs قرار بده. دامنهٔ برنامه باید ثابت و برای گوگل قابل قبول باشد.

    APP_BASE_URL/auth/google/callback

  4. تنظیمات را روی سرور ذخیره کن

    فایل .env.example را به .env کپی کن؛ Client ID، Client Secret، آدرس عمومی برنامه و یک SESSION_SECRET تصادفی را وارد کن. سپس سرور را دوباره اجرا کن.

    رمز، Client Secret یا توکن را در چت یا مخزن عمومی نفرست.

قبل از اتصال بدان

این محیط به سرورهای گوگل دسترسی خروجی ندارد. برای اتصال واقعی، برنامه را روی دستگاه یا میزبانی‌ای اجرا کن که به گوگل دسترسی دارد.

با ری‌استارت سرور، نشست و توکن‌ها پاک می‌شوند. در حالت Testing گوگل هم ممکن است مجوز پس از ۷ روز منقضی شود.

حساب Brand Account درست را در ورود انتخاب کن؛ اگر کانال انتخاب‌شده آهنگ‌بان نباشد هشدار می‌دهیم.

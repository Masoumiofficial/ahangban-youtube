- تصویر مجریان در همان نمای اصلی حفظ و برای تناسب طبیعی‌تر، اندازهٔ نشستهٔ آن‌ها ۵٪ کمتر شده است.
- نوردهی ۶٪ کمتر، کنتراست و اشباع کمی نرم‌تر و سایهٔ تماس ملایم اضافه شده است؛ چهرهٔ جدیدی تولید نشده است.
- تمام پیکسل‌های بیرون از لایهٔ مجریان و سایهٔ آن‌ها با مستر خالی یکسان‌اند. میز و تجهیزات جلوی بدن‌ها از پایه حفظ شده‌اند.
- صدای آوا همان فایل‌های منتخب قبلی `voice-00` است؛ چهار گفتار سجاد از WAVهای منتخب جدید `voice-02` گرفته شده، نه صدای مرد قدیمی `voice-01`.
- لوگوی رسمی با همان شکل و رنگ روی تابلوی خالی اضافه می‌شود؛ فقط هالهٔ نور، چرخهٔ نرم شش‌ثانیه‌ای دارد. مستر پایه همچنان خالی است.

- نماهای دیگر استودیو تولید نشده‌اند. کارت موسیقی، گرافیک تدوین روی همان نماست، نه تغییر دکور.

## منابع

متن همان سناریوی پنج‌قطعه‌ای تأییدشده است و در `dialogue.fa.json` ثبت شده است.
پنج MP3 و پنج کاور اصلی با `git cat-file` از نسخهٔ مشخص زیر بازیابی می‌شوند؛ فایل‌ها دوباره تولید یا جایگزین نمی‌شوند:

- مخزن: `Masoumiofficial/ahangban-youtube`
- نسخه: `d318f9f7095ab6c966a743ad3461e8f6fab0db34`
- پوشه: `Artist/1-Mohsen-Chavoshi/`

ترتیب: کجایی (با ذکر سینا سرلک)، سنگ صبور، امیر بی‌گزند، برقص آ، بیست هزار آرزو.
شروع نمونه‌ها در فایل منبع به‌ترتیب ۴۵، ۴۰، ۵۰، ۳۵ و ۴۰ ثانیه؛ مدت هرکدام ۱۲ ثانیه است.
این نقاط ادعای ترجیع‌بند یا بهترین بخش آهنگ ندارند. حقوق آثار و تصاویر مستقلاً تأیید نشده؛ کوتاه‌بودن نمونه یا ذکر منبع تضمین مجوز و رفع Content ID نیست.

## بازسازی

خروجی‌ها و منابع بزرگ زیر `rendered/video-003-studio/` هستند و Git آن‌ها را نادیده می‌گیرد.
فقط MP4 بازبینی برای دسترسی مستقیم کاربر در `downloads/` نگهداری می‌شود.
فایل‌های صدای منتخب باید از تولید قبلی در مسیرهای زیر موجود باشند:

- آوا: `rendered/video-002/audio/01,03,04,05,07,08,09.mp3`
- سجاد: `rendered/studio-voice-revision/02,10,11,06.wav`

اسکریپت صدای ابری تولید نمی‌کند؛ اگر فایل منتخب مفقود باشد متوقف می‌شود، نه اینکه صدای دیگری جایگزین کند. شناسه‌های صدا مخصوص جلسه‌اند و voice model قابل‌حمل نیستند.

```sh
python -m pip install -r content/003-chavoshi-studio/requirements.txt
python studio/ahangban-signature/tools/validate_master.py
python studio/ahangban-signature/tools/validate_hosts.py
python content/003-chavoshi-studio/build_video.py --prepare-only
python content/003-chavoshi-studio/build_video.py --render-only
python content/003-chavoshi-studio/validate_video.py
python -m unittest discover -s content/003-chavoshi-studio -p 'test_*.py'
```

رندر با جریان RGB محدود در حافظه انجام می‌شود؛ هالهٔ لوگو در پایین و CORE اصلی در بالا ترکیب می‌شوند. هیچ توکن، کلید، نشست خصوصی یا اتصال انتشار در این اسکریپت استفاده نمی‌شود.
فونت Vazirmatn از نسخهٔ موجود پروژه، با مجوز OFL همان پوشه استفاده می‌شود.

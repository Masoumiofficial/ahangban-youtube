# بررسی Chatterbox برای صدای فارسی سجاد و لپ‌تاپ گزارش‌شده

**نتیجه: برای متن‌به‌گفتار مستقیم فارسی انتخاب مناسبی نیست؛ مسیر Voice Conversion آن ارزش یک آزمایش کوتاه دارد، نه تضمین کیفیت.**

نسخهٔ بررسی‌شده: [`5de7a54aa4e5e2baadb0182dde554908b48b85c2`](https://github.com/resemble-ai/chatterbox/tree/5de7a54aa4e5e2baadb0182dde554908b48b85c2). شاخهٔ پیش‌فرض مخزن `master` است. این بررسی خواندن README و کد بوده؛ مدل دانلود، نصب یا اجرا نشده است.

## زبان و مجوز

| بخش | یافته | نتیجه برای آهنگ‌بان |
|---|---|---|
| Multilingual V3 | README مدل را 500M معرفی می‌کند؛ دیکشنری `SUPPORTED_LANGUAGES` در کد ۲۳ زبان دارد و `fa` در آن نیست | موتور آمادهٔ فارسی معرفی نمی‌شود |
| Turbo | در README انگلیسی است | راه‌حل مستقیم متن فارسی نیست |
| Nano | 110M و برای CPU معرفی شده، اما انگلیسی است | سبک‌بودن به‌تنهایی مشکل فارسی را حل نمی‌کند |
| ChatterboxVC | ورودی گفتار پایه و صدای مرجع هدف را می‌گیرد؛ ورودی متن ندارد | گزینهٔ آزمایشی برای تبدیل رنگ صدای یک گفتار فارسی از پیش ساخته‌شده |
| مجوز مخزن | MIT | نکتهٔ مثبت برای کد؛ شرایط وزن‌ها، موتور فارسی پایه و هر وابستگی پیش از انتشار جدا بررسی شوند |

فهرست زبان‌ها و امضای تابع VC با AST استخراج شدند؛ کد مدل برای این بررسی اجرا نشده است. [ثبت ماشینی یافته‌ها](chatterbox-audit.json).

## تطبیق با سیستم کاربر

اطلاعات گزارش‌شده: **Intel Core i7-8550U، رم ۸GB، حافظهٔ اعلام‌شدهٔ ۶۰GB، فرکانس نمایش‌داده‌شدهٔ 1.80/1.99GHz**. هنوز روشن نیست ۶۰GB کل ظرفیت دیسک است یا فضای خالی؛ کارت گرافیک مجزا هم گزارش نشده است.

- نمونهٔ رسمی و کد VC مسیر `cpu` دارند؛ وجود این مسیر اثبات سرعت یا مصرف RAM مناسب روی همین لپ‌تاپ نیست.
- با رم ۸GB، اجرای کل پشتهٔ PyTorch و مدل در کنار ویندوز و برنامه‌های دیگر می‌تواند تحت فشار حافظه قرار بگیرد. زمان تولید یا کمینهٔ حافظهٔ این لپ‌تاپ را بدون آزمون عددگذاری نمی‌کنیم.
- مدل‌های TTS حدود 500M را صرفاً برای آزمایش فارسیِ پشتیبانی‌نشده نصب نمی‌کنیم. آزمایش VC از مدل و مسیر جدا استفاده می‌کند و باید مصرف واقعی‌اش اندازه‌گیری شود.
- ادعای سرعت Nano روی CPU در README، بنچمارک لپ‌تاپ کاربر نیست؛ آن را به i7-8550U تعمیم نمی‌دهیم.
- اگر ۶۰GB فضای خالی باشد، ظرفیت دیسک احتمالاً اولین محدودیت یک آزمایش کوچک نیست، ولی اندازهٔ دقیق همهٔ وابستگی‌ها و کش مدل هنوز اندازه‌گیری نشده است. اگر کل ظرفیت باشد، ابتدا فضای خالی بررسی شود.
- برنامهٔ آزمایش: تک‌پردازه، یک کلیپ حدود ۵ تا ۱۰ ثانیه، بستن برنامه‌های سنگین و ثبت RAM/زمان واقعی. اجرای بلادرنگ هدف مرحلهٔ اول نیست.

## مسیر کاربردی پیشنهادی

`متن تازهٔ فارسی → گفتار پایهٔ فارسیِ دارای حق استفاده → ChatterboxVC یا OpenVoice → بازبینی شباهت به صدای سجاد`

این مسیر در صورت قبولی آزمون، نیاز به ضبط برای هر سناریو را برطرف می‌کند؛ اما سبک و آهنگ اجرای گفتار پایه هم روی نتیجه اثر می‌گذارد. هنوز حفظ دقیق تلفظ فارسی و شباهت به کاربر با ChatterboxVC آزمایش نشده است.

### نکتهٔ مهم دربارهٔ مرجع فعلی

کد `ChatterboxVC.set_target_voice` فقط **۱۰ ثانیهٔ اول** فایل مرجع را برای شرط‌گذاری برمی‌دارد. مرجع اصلی سجاد در ابتدا و بین جمله‌ها سکوت دارد؛ بنابراین نباید فایل ۴۹ثانیه‌ای را بدون انتخاب نمونهٔ مناسب مستقیم به آن داد. پیش از آزمون، یک بخش کوتاهِ پرگفتار و بدون بریدن کلمه انتخاب و بازبینی شود. این انتخاب هنوز به‌عنوان مرجع نهاییِ کلون تأیید نشده است.

وزن‌ها در کد از Hugging Face دریافت می‌شوند؛ دسترسی مستقیم به آن میزبان در سندباکس حاضر مجاز نیست. در نتیجه آزمایش واقعی در این محیط انجام نشده است. برای نصب محلی روی رایانهٔ کاربر، دریافت یک‌بارهٔ وزن‌ها و وابستگی‌ها لازم خواهد بود؛ فایل صدای شخصی لازم نیست به سرویس ابری فرستاده شود. رفتار کاملاً آفلاین پس از نصب نیز هنوز آزموده نشده است.

## تصمیم فعلی

Chatterbox جایگزین قطعی مسیر قبلی نمی‌شود. **VC آن به فهرست نامزدهای آزمایش در کنار OpenVoice افزوده شد**؛ TTS مستقیم فارسی و Nano انگلیسی برای تولید فعلی انتخاب نشده‌اند. هنوز کلون، خروجی تبدیل‌شده، بنچمارک روی لپ‌تاپ یا ویدیوی تازه ساخته نشده است. اصل ضبط کاربر و لباس مشکی سجاد بدون تغییرند.

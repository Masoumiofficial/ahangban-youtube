## طراحی و تدوین

- سبک مجلهٔ تصویری موسیقی: زمینهٔ تیرهٔ بافت‌دار، تایپوگرافی فارسی درشت، پالت کرم/کهربایی و رنگ فصل‌های متفاوت.
- فقط کاورهای اصلی ارائه‌شده؛ ورود عنوان، چیدمان لایه‌ای، حرکت نرم و تغییر مقیاس محدود، سایهٔ ظریف، پیشرفت قطعه و گذار کوتاه بین بخش‌ها.
- ویژوالایزر ۴۸باندی از FFT صوت واقعی؛ انیمیشن تصادفی یا ادعای تشخیص دقیق ضرب نیست. این گرافیک برای نمایش است، نه ابزار اندازه‌گیری آزمایشگاهی.
- لوگوی رسمی با همان ترکیب، رنگ و نسبت، روی زمینهٔ روشن برای خوانایی؛ هیچ لوگو یا حامی خیالی اضافه نشده است.
- هیچ عکس یا فریم مجری، استودیو یا تست لب‌خوانی وارد تصویر نشده است. ورودی ویدیوی قبلی **فقط به‌عنوان منبع صوت** استفاده می‌شود.

«بدون مجری تصویری» به معنی حذف عکس از خود کاور آثار نیست: روی کاورهای اصلی ممکن است چهرهٔ هنرمند یا بازیگر دیده شود. عکس تازه‌ای از هنرمند اختراع یا تولید نشده است. کاور سنگ صبور در منبع فقط 200×200 است؛ جزئیات تازه‌ای به آن نسبت نداده‌ایم و محدودیت وضوح منبع باقی است.

## صدا و تفاوت دو نسخه

**یوتیوب:** همان ۱۱ نوبت گفتار و پنج نمونهٔ ۱۲ثانیه‌ای نسخهٔ کامل، بدون تغییر سناریو یا تولید دوبارهٔ صدا. payload صوت AAC مستقیماً کپی شده و SHA آن با نسخهٔ اصلی برابر است. سجاد همان ضبط واقعی کاربر است؛ آوا همان گفتارهای منتخب `voice-00`. ۳۷ بخش زیرنویس گفتار دارد.

**ریلز:** تدوین جداگانه است، نه برش عمودی ویدیوی افقی. شروع با حدود چهار ثانیه سؤال واقعی سجاد، سپس پنج نمونهٔ پنج‌ثانیه‌ای آهنگ، و پایان با دعوت آوا به کامنت و مکث کوتاه کارت پایانی. قطعه‌ها از همان صوت نسخهٔ کامل استخراج شده‌اند. فقط فید کوتاه لبه‌ها برای حذف کلیک اعمال شده؛ زیر و بمی/سرعت/هویت صدا عوض نشده است. نام کاربری اینستاگرام حدس زده نشده؛ نشانی وب‌سایت معتبر آهنگ‌بان استفاده شده است.

عنوان و کاور برای 9:16 جدا طراحی شده‌اند. نوشته‌های اصلی و زیرنویس‌ها از حاشیهٔ راست و پایین فاصله دارند؛ چیدمان رابط اینستاگرام ممکن است با دستگاه یا نسخهٔ برنامه فرق کند، بنابراین پیش از انتشار پیش‌نمایش خود برنامه را هم ببینید.

## بررسی انجام‌شده

- دیکد کامل هر دو MP4، قالب/مدت/fps، هش فایل‌ها و تطبیق کاورهای بازیابی‌شده با Git blobهای مرجع پاس شدند.
- یوتیوب: تطبیق دقیق payload صوت با نسخهٔ قبلی پاس شد؛ پیک دیکدشدهٔ استریو ‎−1.5dBFS.
- ریلز: هفت بخش واقعی صوت (دو گفتار + پنج آهنگ) با بازه‌های متناظر نسخهٔ اصلی مقایسه شدند؛ سکوت ناخواسته و جابه‌جایی محتوای صوت بررسی شد. [نتیجهٔ دقیق](delivery/reel/qa-report.json).
- تغییر فریم‌های کاور و تغییر طیف صوتی بررسی شده؛ PNG/JPGهای تبلیغاتی جای MP4 نهایی تحویل نشده‌اند.
- فریم‌های واقعی دیکدشدهٔ هر دو ویدیو شامل آغاز، آهنگ‌ها و پایان به‌صورت تصویری بررسی شدند.
- تست‌های سناریو/تایم‌لاین، عدم هم‌پوشانی، دو گویندهٔ موجود، پنجرهٔ نمونه‌های موسیقی، حفظ منبع، نسبت تصویر، زیرنویس و طیف مبتنی بر صوت پاس شدند.

این بررسی، تأیید شنیداری تلفظ یا مرز برش جمله نیست. زیرنویس‌ها از زمان‌بندی تخمینی قبلی‌اند، نه هم‌ترازی واژه‌به‌واژه. پیش از انتشار، مخصوصاً اتصال سؤال سجاد و پایان آوا در ریلز را با صدا بازبینی کنید.

## حقوق و انتشار

پنج قطعه: کجایی (محسن چاوشی و سینا سرلک)، سنگ صبور، امیر بی‌گزند، برقص آ، بیست هزار آرزو. کاورها و نمونه‌های صوتی از منابعی هستند که کاربر قبلاً ارائه کرده است. **حقوق موسیقی/تصویر مستقلاً تأیید نشده؛ کوتاه‌بودن نمونه یا درج نام، مجوز یا تضمین رفع Content ID نیست.** این موضوع در هر دو پلتفرم باید پیش از انتشار بررسی شود. هیچ فایل خودکار در یوتیوب یا اینستاگرام منتشر نشده است.

## بازسازی

این مسیر به مدل، GPU، Colab، حساب سرویس یا ضبط تازه نیاز ندارد. منابع اصلی ویدیو/لوگو و فونت در مخزن هستند؛ کاورها از Git revision دقیق `d318f9f7095ab6c966a743ad3461e8f6fab0db34` بازیابی می‌شوند. رندر میانی و WAV جدا در `rendered/` نادیده گرفته می‌شوند، نه Git عمومی.

```sh
python -m venv .venv
.venv/bin/pip install -r content/006-faceless-music/requirements.txt
.venv/bin/python content/006-faceless-music/build_video.py --kind youtube
.venv/bin/python content/006-faceless-music/build_video.py --kind reel
.venv/bin/python content/006-faceless-music/validate_video.py --kind youtube
.venv/bin/python content/006-faceless-music/validate_video.py --kind reel
.venv/bin/python content/006-faceless-music/package_delivery.py
.venv/bin/python -m unittest discover -s content/006-faceless-music -p 'test_*.py'
```

نسخه‌های قدیمی استودیویی و منابع تأییدشده برای سابقه نگه داشته شده‌اند؛ حذف مسیر چهره از تولید فعلی به معنی حذف فایل‌های تاریخی کاربر نیست. تا درخواست تازهٔ کاربر، لب‌خوانی و پردازش چهره را دوباره راه نیندازید.

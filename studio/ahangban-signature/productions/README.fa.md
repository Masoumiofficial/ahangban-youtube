کاربر کت‌وشلوار مشکی و استفاده از صدای واقعی خودش در مرحلهٔ بعد را درخواست کرد.

فقط ناحیهٔ لباس تغییر کرده است؛ صورت سجاد و تمام آوا با نمای 001 پیکسل‌به‌پیکسل مقایسه شده‌اند و ثابت‌اند. مستر خالی تغییر نکرده است. نمای 001 برای حفظ نسخهٔ قبلی ویدیو دست‌نخورده نگهداری می‌شود. صدای واقعی هنوز دریافت نشده و ویدیوی جدید تولید نشده است.

## چیدمان تأییدشده
از دید دوربین: **سجاد چپ، آوا راست**. لباس تاریخی نمای 001 سجاد کت قهوه‌ای، پیراهن مشکی و کراوات طلایی است؛ پیش‌فرض جدید نمای 002، کت و پیراهن مشکی است؛ آوا پوشش مشکی و گلدوزی طلایی مرجع را دارد.

این همان قاب روبه‌روی مستر تأییدشده است، نه زاویهٔ جدید. فایل مستر خالی دست‌نخورده است. برای جلوگیری از بازطراحی استودیو، تنها سیلوئت‌های مجریان از خروجی تولید تصویر استخراج و بر مستر قرار گرفته‌اند؛ میکروفون، بازو، هدفون، میکسر و تجهیزات جلوی مجریان از تصویر پایه حفظ شده‌اند. بیرون از آلفای مجریان، پیکسل‌های خروجی دقیقاً با پایه یکسان‌اند. طبیعی است بخشی از قاب‌های پشت سر، پشت مجریان پنهان شود؛ عکس‌ها جابه‌جا یا جایگزین نشده‌اند.

مرجع تولید انسان‌ها ۱۳۶۵×۷۶۸ است و در ترکیب 4K بازنمونه‌برداری شده؛ جزئیات انسانی 4K بومی نیست. تطبیق چهره و ظرافت برش نیازمند بازبینی کاربر است و تضمین تطابق بی‌نقص نیست.

تابلوی لوگو خالی باقی مانده است؛ لایه‌های رسمی لوگو در `../overlays/` مستقل‌اند. این فایل PNG **تصویر ثابت** است و لب‌خوانی ندارد. استفادهٔ ویدیویی همراه صدا، موج صوتی و انیمیشن هالهٔ لوگو در [ویرایش استودیویی](../../../content/003-chavoshi-studio/README.fa.md) مستند شده است.

## بازتولید
از ریشهٔ مخزن با محیط دارای Pillow:

```sh
python studio/ahangban-signature/tools/compose_hosts.py --wardrobe black
python studio/ahangban-signature/tools/validate_master.py
python studio/ahangban-signature/tools/validate_hosts.py --shot 002
```

برای بازتولید صرفاً نمای تاریخی 001 از `compose_hosts.py --wardrobe brown` و `validate_hosts.py --shot 001` استفاده شود؛ این دستور به معنی بازگشت پوشش پیش‌فرض به قهوه‌ای نیست.

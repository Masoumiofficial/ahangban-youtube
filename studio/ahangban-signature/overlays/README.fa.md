# لایه‌های مستقل لوگو

تصویر پایهٔ استودیو عمداً لوگو ندارد. هر دو فایل PNG این پوشه شفاف و هم‌اندازهٔ
تصویر اصلی (۳۸۴۰×۲۱۶۰) هستند و در مختصات اصلی تابلو قرار دارند.

1. تصویر پایهٔ استودیو در پایین.
2. `AHANGBAN-LOGO-GLOW.png` برای نور پشت لوگو.
3. `AHANGBAN-LOGO-CORE.png` شامل همان شکل، رنگ و تایپوگرافی لوگوی اصلی.

CORE را تغییر رنگ یا دوباره تایپ نکنید. برای افکت نئون، فقط شدت/شفافیت GLOW و در
شروع نمایش شفافیت کل لایه‌ها را آرام تغییر دهید. تغییر شدت نرم باشد، نه چشمک سریع.
این‌ها لایه‌های ثابتِ آمادهٔ تدوین‌اند، نه ویدیوی نئون ساخته‌شده یا صدور تأیید کاربر برای انیمیشن نهایی.
لوگوی اصلی کامل و بدون تغییر در `../references/ahangban-logo-horizontal-color.png` حفظ شده است.

اجرای ویدیویی چرخهٔ نرم شش‌ثانیه‌ای شدت GLOW در [ویرایش استودیویی](../../../content/003-chavoshi-studio/README.fa.md) انجام شده است. CORE بالای نور و بدون بازطراحی باقی می‌ماند؛ فایل‌های این پوشه همان PNGهای مستقل‌اند.
